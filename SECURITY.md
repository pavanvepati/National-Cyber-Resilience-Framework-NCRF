# Security Policy

## Responsible Disclosure Policy
We encourage anyone finding a security vulnerability to report it to us via the contact information provided in this document. We treat all reports confidentially and will work with you to resolve any issues.

## Security Best Practices
- **Mandatory MFA for Admin Access**: Multi-Factor Authentication must be enabled for all administrative accounts to prevent unauthorized access.
- **Regular Patching Requirements**: All systems must be patched promptly to address known vulnerabilities. A regular schedule for reviewing and applying updates should be established.
- **Data Minimization Principles**: We adhere to the principles outlined in the Data Protection and Digital Privacy (DPDP) Act 2023, ensuring that only necessary data is collected and retained. Any unnecessary data will be deleted according to our data retention policy.

## Vulnerability Reporting Procedures
If you discover a vulnerability, please report it to us directly through our designated security contact. Include as much detail as possible to help us investigate the issue promptly.
